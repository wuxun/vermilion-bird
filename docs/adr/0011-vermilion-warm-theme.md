# ADR 0011：采用暖白朱红的朱雀视觉主题

## 状态

已接受，2026-07-29。

## 背景

中性深色壳层虽然简洁，但弱化了 Vermilion Bird 的朱雀品牌识别，也不符合产品希望
传达的温暖、主动和有生命力的气质。部分旧组件还各自使用深灰或棕色硬编码，导致同一
应用出现多套视觉语言。

## 决策

1. 大面积背景使用暖白和暖灰，不使用纯白、冷灰或大面积红色。
2. 品牌、主动作、选中态、焦点态和目标提示使用深朱红。
3. 正文使用暖炭黑，次级文字使用低饱和暖灰，保证长时间阅读。
4. 成功、警告、信息和错误保留语义颜色，不把所有状态强行改成红色。
5. 主按钮白字与朱红底、正文与暖白底均满足 WCAG AA 常规文本对比度。
6. GUI 组件只消费 `frontends.theme.Colors` 设计令牌，禁止新增页面级主题色硬编码。

## 结果

- 保留 Codex-like 的低噪声布局和渐进交互，同时建立明确的朱雀品牌辨识度。
- 主对话、工作概览、执行中心、决策卡片、子 Agent 和配置弹窗使用同一视觉语言。
- 后续可在同一语义令牌之上增加深色模式，而无需改写业务组件。
