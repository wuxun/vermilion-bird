# ADR 0009：采用 Codex-like 单侧栏壳层与共享设计系统

## 状态

已接受，2026-07-29。第 2 项已由 ADR 0010 部分取代；视觉配色由 ADR 0011 取代。

## 背景

旧 GUI 同时存在窄导航栏、会话侧栏、暖色内容区、独立模型状态栏和大量常驻功能按钮。
这些元素都能工作，但用户需要先理解产品能力分区，才能开始任务；任务中心与对话页也
使用了不同的视觉语言。

产品目标是本地优先的 AI 工作执行台。核心体验应围绕任务、过程、审批和交付结果，
而不是展示功能目录。

## 决策

采用 Codex-like 的信息架构与交互原则：

1. 只保留一个左侧栏，承载全局导航和最近上下文。
2. 对话与任务继续是两个一级工作区，但使用同一壳层。
3. 当前上下文标题固定在顶部，低频动作渐进展示。
4. 消息画布限制阅读宽度，Composer 固定在底部。
5. 工具、执行细节和诊断信息默认折叠或隐藏。
6. 任务、执行中心和决策卡片共享设计令牌。
7. 所有工作区共享设计令牌，具体品牌配色由独立视觉 ADR 演进。

该决策复用通用产品模式，不使用 OpenAI Logo、Codex 品牌名称、原始图标、截图素材或
专有实现。

## 结果

- 主界面的层级和操作数量明显减少。
- 对话与任务工作区的切换成本降低；后续由 ADR 0010 进一步统一为工作线程与工作概览。
- 审批、自动化结果和工具执行仍保留完整能力，但不再争夺默认注意力。
- 后续 GUI 必须优先扩展共享设计令牌和组件，不得通过页面级硬编码重新引入浅色孤岛。

## 后续

- 增加全局命令面板和完整键盘导航。
- 增加文件拖放、附件预览和上下文管理。
- 为高分屏、VoiceOver 和跨平台字体建立 GUI E2E 基线。
