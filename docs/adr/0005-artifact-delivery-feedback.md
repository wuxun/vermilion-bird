# ADR 0005：Artifact 交付、反馈与采纳率

- 状态：Accepted
- 日期：2026-07-28

## 背景

仅以 Run 成功或模型返回文本衡量任务质量，会把“执行结束”误认为“用户目标达成”。
Artifact 已经是任务交付物实体，但缺少稳定导出、用户反馈和产品质量指标。

## 决策

- 用户可对 Artifact 追加 `accepted`、`needs_revision` 或 `rejected` 反馈。
- 反馈采用不可变事件历史；同一 Artifact 的最新事件作为当前决定。
- Eval 聚合报告按“最新决定”计算 Artifact 采纳率；没有反馈时返回 `null`，不把未评价
  误算为拒绝。
- 内嵌内容、本地文件和链接都可导出。
- 导出先写同目录临时文件再原子替换，默认拒绝覆盖已有文件。
- 远程链接当前导出为链接文本，不隐式下载网络内容。
- CLI、App 和 GUI 使用同一个 WorkItem 应用服务入口。

## 结果

产品可以区分执行完成率、Artifact 达标率和真实采纳率。后续“从成功任务生成工作流”
应优先使用已接受的 Artifact 作为成功证据；需修改反馈可作为计划修订和提示词优化的输入。
